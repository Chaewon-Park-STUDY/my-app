# 📱 My App — 아이디어 메모

## 💡 핵심 아이디어

아이폰 갤러리 용량이 부족해서, 사진은 네이버 블로그에 올리고 갤러리에서 삭제하는 방식으로 관리 중.
- 블로그에 올린 사진 → 블로그에서 다시 다운로드 가능 ✅
- 블로그에 올린 동영상 → 재생만 가능, 다운로드 불가 ❌

**→ 동영상만 따로 클라우드에 저장하고, 필요할 때 다시 다운받을 수 있는 앱이 필요함**

---

## 🔍 기존 앱과의 차이

| 앱 | 문제점 |
|---|---|
| Google Photos | 15GB 초과 시 유료, 전체 갤러리 관리 목적 |
| iCloud | 동기화 방식 — 기기에서 삭제하면 클라우드에서도 삭제됨 |
| OneDrive | 동영상 전용 아님, 재다운로드 UX가 불편 |

기존 앱들은 전체 갤러리 백업 목적이거나, **동영상 전용 + 재다운로드 UX**에 특화된 앱이 없음.

---

## ✅ 원하는 기능

1. 동영상만 선택해서 클라우드에 업로드
2. 업로드 확인 후 갤러리에서 삭제 (용량 확보)
3. 앱 내 목록에서 언제든 다시 다운로드 가능
4. 이 흐름이 앱 하나에서 심플하게 완결

---

## 🛠 기술 스택 후보 (미정)

- iOS 앱 (Swift / SwiftUI)
- 백엔드 저장소: iCloud Drive / Google Drive / Dropbox 중 검토 필요
